## 2. THE ROOT CAUSE (found after DQ-ORDER3 — this is the key finding)

**D4 does not lose because of false positives. It loses 158 TRUE POSITIVES that
D1 catches.**

| D4 vs D1 (dq3, 160 s) | count |
|---|---|
| TP gained | +224 |
| FP added | +89 |
| **TP LOST** | **−158** |
| FP avoided | 0 |

For those 158 lost TPs:

| | D1 | D4 |
|---|---|---|
| `psi_fuse` | 0.1770 | **0.0020** |
| `phi` | 1.0000 | **0.3480** |
| `khat` | — | **4 (155 of 158)** |

**Mechanism** (`08_detection_engine.h:2390`):
```c
const float *w = (k_hat_i >= 0 && k_hat_i < K_ATTACK)
                 ? g_fusion.sig_w_k[k_hat_i] : g_fusion.sig_w_global;
```
Only a GAT-bearing arm derives `k̂`. `k̂=4`'s signature-weight set assigns ~zero
weight to the bits these beacons carry:
```
attack 4: [0.0045, 0, 0, 0, .3275, .2836, .3844, 0, 0]
global  : [0.0976, 0, 0, .1685, .2018, .2214, .2310, 0, .0797]
```
So enabling the GAT ERASES rule evidence on a misroute. `fusion_weights.json`
itself documents slot 4 as a known misrouting sink ("head 3 (a4 slot) is where a3
beacons are misrouted").

**k̂=4 timing:** first occurs at **t=32.0**, 210 occurrences to t=152, median t=50.
So no effect is visible before t≈32 — do not judge the fix at cutoff 30.

**Fix implemented: `--psi_cond_floor`** — attack-conditioned ψ is floored at the
global-weight ψ (`max(s, s_global)`). Conditioning may still RAISE ψ; it can no
longer erase evidence. **D1 is provably unaffected** (k̂ < 0 there → global set
already used → floor is a no-op). This is the ONLY mechanism found that helps
GAT arms by construction; ring_detect and Fix B both helped D1 as much or more,
which is why they compressed the ordering.

**Projection (arithmetic, NOT measured):** recovering ~155 TPs gives
D4 ≈ 0.828 vs D1 0.824 → **+0.004**, flipping the deficit's sign.

### Per-beacon log format (the analysis backbone)

simulator's own confusion matrix before its output is trusted:
```

 thetaS=19.740 S_over_thetaS_raw=0.205 S_over_thetaS_clamped=0.205
```

Ghost IDs are `vid >= 10000` (`GHOST_VID_BASE`). `gt_pois` is ground truth,
`full_anom` is the fusion decision, `sig_mask` bit b = signature b
